3 hệ thống/trang hoàn toàn tách biệt.

Nên làm kiểu:

                    LOGIN
                      │
          ┌───────────┼───────────┐
          ↓           ↓           ↓
       ADMIN       MANAGER     EMPLOYEE
          │           │           │
          ↓           ↓           ↓
    Admin Dashboard  Manager     Employee
                     Dashboard    Dashboard
1. Admin

Admin dashboard tập trung vào quản trị hệ thống:

┌──────────────────────────────┐
│ ADMIN                        │
├──────────────────────────────┤
│ Dashboard                    │
│ Quản lý tài khoản            │
│ Quản lý quyền                │
│ Quản lý nhân viên            │
│ Cấu hình hệ thống            │
│ Nhật ký hệ thống              │
└──────────────────────────────┘

Admin không nhất thiết phải xử lý bán hàng hằng ngày.

2. Manager

Đây là giao diện quản lý cửa hàng:

┌──────────────────────────────┐
│ QUẢN LÝ                      │
├──────────────────────────────┤
│ Tổng quan                    │
│ Quản lý bán hàng             │
│ Đơn hàng                     │
│ Hóa đơn                      │
│ Sản phẩm                     │
│ Kho hàng                     │
│ Khách hàng                   │
│ Nhân viên                    │
│ Doanh thu                    │
│ Báo cáo                      │
│ Thông báo                    │
└──────────────────────────────┘

Manager nhìn được gần như toàn bộ hoạt động cửa hàng.

3. Employee

Nhân viên chỉ cần giao diện phục vụ bán hàng:

┌──────────────────────────────┐
│ NHÂN VIÊN                    │
├──────────────────────────────┤
│ Bán hàng                     │
│ Tạo đơn                      │
│ Đơn hàng cần xử lý           │
│ Hóa đơn                      │
│ Sản phẩm                     │
│ Khách hàng                   │
│ Thông báo                    │
└──────────────────────────────┘

Không cần cho nhân viên thấy:

❌ Quản lý nhân viên
❌ Doanh thu toàn cửa hàng
❌ Xuất báo cáo
❌ Phân quyền
❌ Cấu hình hệ thống
❌ Các chức năng quản trị
Nhưng có một điểm rất quan trọng

Đừng chỉ ẩn menu.
Ví dụ Employee không nhìn thấy:

[Quản lý nhân viên]

nhưng nếu nó biết URL:

/admin/employees

mà vẫn truy cập được thì phân quyền coi như chưa làm.

Phải có cả:

UI
 ↓
Ẩn chức năng không có quyền
 ↓
Backend
 ↓
Kiểm tra ROLE/PERMISSION
 ↓
Cho phép / từ chối

Ví dụ Servlet:

if (!"MANAGER".equals(user.getRole())
        && !"ADMIN".equals(user.getRole())) {

    response.sendError(HttpServletResponse.SC_FORBIDDEN);
    return;
}
Các chức năng dùng chung thì dùng chung UI, còn dashboard/sidebar khác nhau theo role.

Ví dụ:

Employee
    └── /products
          └── xem sản phẩm

Manager
    └── /products
          └── quản lý sản phẩm

Cùng một module nhưng quyền thao tác khác nhau.
Với 2003 Store hiện tại, mình sẽ chọn mô hình này
                    LOGIN
                      │
             ┌────────┴────────┐
             │                 │
         Kiểm tra ROLE      Session
             │
     ┌───────┼────────┐
     ↓       ↓        ↓
   ADMIN   MANAGER  EMPLOYEE
     │       │        │
     ↓       ↓        ↓
  Admin    Manager  Employee
Dashboard  Dashboard Dashboard

3 dashboard riêng + các module dùng chung + backend kiểm tra quyền.
Và với tình huống cửa hàng của bạn, thu ngân không nhất thiết phải thành role thứ 4. 
Có thể để là EMPLOYEE nhưng tài khoản thu ngân được cấp thêm quyền PAYMENT_CONFIRM. 
Như vậy sau này 1 nhân viên bán hàng và 1 thu ngân có cùng role nhưng quyền thao tác khác nhau.
